# 🎬 Netflix SQL Data Analysis

## 📌 Project Overview

This project focuses on analyzing Netflix-related data using SQL and MySQL. The objective is to extract meaningful insights from users, movies, subscriptions, and watch history.

## 🛠️ Tools Used

- MySQL
- SQL
- MySQL Workbench

## 🗄️ Database Tables

- Users
- Movies
- Subscriptions
- WatchHistory

## 🔍 Analysis Performed

- User analysis
- Movie analysis
- Subscription analysis
- Watch history analysis
- Revenue analysis
- Popular movie analysis

## 🎯 Project Objectives

- Analyze customer and movie data
- Understand subscription patterns
- Identify popular movies
- Analyze user viewing behavior
- Generate useful business insights using SQL

## 📂 Project File

`project netflix sql.sql` contains the SQL queries used for database creation, data manipulation, and analysis.
